# DBMS SQL Study Reader

A static website for reading the original DBMS and SQL PDFs in sequence.

## What It Includes

- A reader that embeds the original PDF files from `DBMS/SQL`.
- Dark mode with saved preference.
- Per-chapter progress tracking in the browser.
- Overall completion tracking.
- Search/filter across PDF titles and descriptions.
- Previous/Next navigation.
- PDF zoom controls.
- Links back to the original source PDFs in `DBMS/SQL`.

The original PDFs are not modified.

## Publish With GitHub Pages

1. Create a new GitHub repository.
2. Upload this whole folder, including `index.html`, `styles.css`, `script.js`, and `DBMS`.
3. In GitHub, open the repository settings.
4. Go to Pages.
5. Set the source to `Deploy from a branch`.
6. Choose the `main` branch and `/root`, then save.
7. Open the GitHub Pages URL after GitHub finishes publishing.

Keep the uppercase `DBMS` folder name unchanged, because GitHub Pages paths are case-sensitive.

## Local Preview

Open `index.html` directly, or run the folder through a local web server. Some browsers show PDF embeds more reliably through GitHub Pages or a local server.
